\problemname{Sum of Squares}

You are given an integer $N$, followed by $N$ integers.
Compute the sum of squares of these integers.

\begin{Input}
The first line contains an integer $N$ ($1 \le N \le 200000$).
The next line contains $N$ integers.
\end{Input}

\begin{Output}
Print the sum of squares of the given integers!
\end{Output}

\nextsample
\sampleinput
3
1 2 3
\sampleoutput
14
